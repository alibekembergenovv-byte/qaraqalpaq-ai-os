## 2026-10-10 - Prisma global singleton and createMany for batch inserts
**Learning:** Using `new PrismaClient()` inside individual services or functions bypasses the Next.js global singleton pattern (established in `src/lib/db.ts`), which can lead to connection exhaustion. Furthermore, doing `findUnique` and `create` inside a loop (N+1 problem) severely impacts performance when scraping feeds. However, simply converting to `createMany(..., { skipDuplicates: true })` without ensuring the batch itself is deduplicated via a `Set` will still cause the whole batch insertion to fail if the payload contains duplicates.
**Action:** Always import `prisma` from `@/lib/db`. When performing batch insertions from scraped/external sources, use `createMany` with `skipDuplicates: true`, but *always* ensure application-level uniqueness using a `Set` or similar mechanism before adding items to the batch payload.
