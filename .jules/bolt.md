## 2024-05-18 - [Optimizing RSS Feed Inserts and Fixing PrismaClient connection limits]
**Learning:** For batch insertions when dealing with parsed data (like RSS feeds), you should ensure application-level uniqueness (using a Map) BEFORE passing the batch payload to Prisma `createMany` with `skipDuplicates: true`. A payload with duplicates inside it can cause the entire batch insertion to fail if there's a unique constraint in the DB. Additionally, importing multiple localized instances of `new PrismaClient()` instead of using a global singleton pattern in Next.js will eventually exhaust the DB connection pool during hot reloads and long-running scraping tasks.
**Action:** When implementing `createMany` + `skipDuplicates: true`, always sanitize the batch for duplicates internally first. Enforce importing the shared instance of Prisma (`@/lib/db`) globally and ensure `lib/db.ts` uses the `globalThis` singleton pattern.
